# 全会话监控与简化安装

用户已确认开发：L2，探索 gpt-6.1-sol/medium，研究和实现 gpt-6-luna/xhigh，架构审查 gpt-6.1-sol/high。

## 产品范围

默认打开全会话中心，不绑定调用者聊天、不自动选择最近会话。列出本机可读的所有主会话和子智能体会话，子会话标明所属关系，支持标题、ID 和项目搜索及执行中、历史、状态未知分组。选中后读取独立流程树，保留节点公开过程和结果功能。模型修改必须携带显式所选会话，拒绝隐式目标。

## 数据与隔离

独立目录读取器索引本机 sessions，返回标题、项目、最后记录状态和更新时间；目录不返回正文。状态读取有界、缓存并对缺失或不完整证据标注 unknown；不根据 mtime 推断进程存活。目录分页访问，不硬截断 20 条；目录刷新不覆盖面板已选会话。选中树沿用 generation 隔离。

## 安装和诊断

发布可自包含的预构建归档及 SHA-256，安装脚本检查 Node 20+、Python 3.10+、Codex 插件命令，验证归档并在用户目录新建隔离市场，然后注册和安装。普通用户不执行 npm/编译，不使用 sudo，不改其他插件或客户端内部文件。开发者保留构建命令。

提供 doctor：实际 MCP 初始化、工具发现、资源读取、入口元数据检查；输出每步状态和客户端入口仍需人工验收的提示。插件列表可见与侧边栏可见分开声明，未验证不报告修复完成。

## 验收

超过 20 个会话可以完整分页访问；首次打开不读取当前或最近树；搜索/筛选/选择正常且快速切换不串会话。预构建归档在无 node_modules 环境启动，安装无 npm；无效校验和在任何市场写入前拒绝；doctor 能区分服务与客户端阶段。运行 Python/Node 全套测试并检查浏览器。
